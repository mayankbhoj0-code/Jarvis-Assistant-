# Disaster Management Hub

Interactive disaster management website with a Leaflet map, resources, and a lightweight AI assistant.

## Quick Start

Open `index.html` directly, or serve the folder for geolocation to work reliably:

```bash
bash serve.sh
```

Then visit `http://localhost:5173`.

## Features

- Interactive map with shelters and hazard overlays
- Geolocation and nearest shelter finder
- Toggleable layers and search
- Floating AI assistant with common safety intents
- Preparedness, Response, Recovery, Mitigation sections

## Notes

- Map tiles and data by OpenStreetMap contributors
- This is an educational demo; replace mock data with real feeds when available
